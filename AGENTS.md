# Project instructions

- Never access development or production databases unless explicitly instructed. A local database is allowed.
- Never access development or production AWS unless explicitly instructed.
- Never commit unless explicitly instructed.
- When changing `/games`, a game, its assets, build configuration or shared game code, read and follow [games/PERFORMANCE.md](games/PERFORMANCE.md). Performance is part of the acceptance criteria for adding a game or changing an existing one.
